📱 Android Responsive UI App

Bu proje, modern Android geliştirme prensipleri kullanılarak oluşturulmuş, 
responsive tasarıma sahip, Material Design bileşenleri kullanılan ve 
yatay (landscape) modu destekleyen bir mobil uygulamadır.

🚀 Özellikler
📐 Responsive Tasarım
Farklı ekran boyutlarına uyumlu yapı
Telefon ve tablet desteği
Constraint ve esnek layout kullanımı
Dinamik boyutlandırma ve oran yönetimi

🔄 Landscape (Yatay) Mod Desteği
Yatay ekran için optimize edilmiş layout
Orientation değişimlerinde state korunumu
UI bileşenlerinin yeniden düzenlenmesi

🛠️ Kullanılan Teknolojiler
Kotlin
Android SDK
Material Design Components
ConstraintLayout
View Binding

Büyük Ekran	✅

🎯 Amaç
Bu proje, modern Android UI geliştirme standartlarına uygun, ölçeklenebilir ve kullanıcı deneyimi yüksek bir arayüz oluşturmayı amaçlamaktadır.
